The website provider customers with information about AutoNexa, its services and available vehicles while creating a foumdation for future e-commerce functionality.

The main goal of AutoNexa is to create a simple and professional website that encourages consumers vehicle sales. ## Test and Iterate

I tested the AutoNexa website using browser developer tools at different screen sizes. The website was tested on desktop, tablet and mobile screen sizes to check that the layout and content adjusted correctly. The mobile test was 400 × 681, the tablet test was 768 × 681 and the desktop test was 1024 × 908. I also used responsive CSS with a media query to improve the layout on smaller screens. These tests helped me check that the website was easy to use on different screen sizes.

## Part 3 – Advanced Website Features

### Animations and Transitions
CSS animations and transitions were added to improve the appearance of the website. Buttons and links now have hover effects, and the hero section uses a fade-in animation.

### Dynamic Content and DOM Manipulation
JavaScript was used to load vehicle listings dynamically into the gallery. This makes it easier to display and manage the vehicles on the website.

### Vehicle Search and Filtering
A search feature was added to help users find vehicles by name. Users can also filter vehicles according to their category.

### Gallery Lightbox
A lightbox feature was added to the vehicle gallery. When a user clicks on a vehicle image, it opens in a larger view. Users can close it by clicking the close icon or pressing Escape.

### Forms and Validation
The Contact and Vehicle Inquiry forms were improved using HTML5 and JavaScript validation. AJAX was also added to submit the forms without refreshing the page. Submitted information is sent to the website owner's email address using FormSubmit.

### Search Engine Optimisation (SEO)
SEO improvements were made across the website. These include page titles, meta descriptions, suitable headings, descriptive image names, alternative image text, internal links and relevant keywords.

The website also includes a robots.txt file and an XML sitemap to help search engines find its pages.

### Performance and Security
Some improvements were made to image sizing, video responsiveness and smooth scrolling. HTTPS is provided through GitHub Pages, and additional security-related settings were added to the HTML pages.
