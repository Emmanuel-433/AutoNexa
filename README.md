AutoNexa is a South African vehicle buying and selling website created to make the process of finding and purchasing pre-owned vehicles easier and more convenient. The website provider customers with information about AutoNexa, its services and available vehicles while creating a foumdation for future e-commerce functionality.

The main goal of AutoNexa is to create a simple and professional website that encourages consumers vehicle sales. The website allows customers to browser vehicles, learn about available services and contact AutoNexa, with future plans to introduce features such as vehicle searching, online enquiries, financial and vehicle reservations.

The website contains five main pages: Home, About Us, Services, Gallery and Contact. The home page introduce AutoNexa, the About Us page provides information about the organsation, the Services page explains the services offered, the Gallery displays vehicles and the Contact page customers to make enquiries.

The project is being developed in stages according to the subject submission timeline. The main milestones include planning and research, creating the website structure, developing the home, About Us, Service, Gallery and Contact pages, texting the website, completing the documentation and submitting the finalproject through GitHub.

## Test and Iterate

I tested the AutoNexa website using browser developer tools at different screen sizes. The website was tested on desktop, tablet and mobile screen sizes to check that the layout and content adjusted correctly. The mobile test was 400 × 681, the tablet test was 768 × 681 and the desktop test was 1024 × 908. I also used responsive CSS with a media query to improve the layout on smaller screens. These tests helped me check that the website was easy to use on different screen sizes.
